# Connectors

Which connectors we use today, and how we plan for them.

## Signal and Low-Current Power

- **Use Molex SL connectors with TPA/CPA.**
  *Why:* they've held up very well. *([2026 Off-Season](../../seasons/2026/off-season.md))*

## Clearance

- Leave room for connectors in CAD, especially RJ45 and USB. See [CAD: Model What Sticks Out](../../mechanical/standards/cad.md#model-what-sticks-out).
