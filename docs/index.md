# TorBots Docs

Team-wide documentation for **FRC Team 1197 TorBots**: how the team works, how we design and build robots today, and the record of each season.

This site is separate from the per-project documentation that ships with our software:

- [ScouTor docs](https://frc-team-1197-torbots.github.io/ScouTor/) — scouting system
- [TorKit docs](https://frc-team-1197-torbots.github.io/TorKit/) — engineering analysis toolkit

## How this site is organized

- **Team, Mechanical, Electrical, and Programming describe how we do things today.** The subteam standards hold every rule we've learned, with the reason and the season it came from. When a new lesson changes a rule, the rule is updated in place.
- **Seasons is the record.** Each season's plan and retros live there, and each lesson links to the standard it changed. You never need to read through past seasons to find the current answer.

- Need this season's plan and schedule? See the [2027 Season Plan](seasons/2027/plan.md).
