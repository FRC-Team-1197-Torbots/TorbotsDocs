# TorBots Docs

Team-wide documentation for **FRC Team 1197 TorBots** — the umbrella site for onboarding, team structure, subteam guides, and build season process.

This site is separate from the per-project documentation that ships with our software:

- [ScouTor docs](https://frc-team-1197-torbots.github.io/ScouTor/) — scouting system
- [TorKit docs](https://frc-team-1197-torbots.github.io/TorKit/) — engineering analysis toolkit

Use this site for anything that isn't specific to one piece of software: how the team is organized, what to do as a new member, how build season runs, and where to find shared resources.

## Where to start

- New to the team? Start with [New Member Onboarding](getting-started/onboarding.md).
- Want to understand how we choose what to build each season? See [Robot Design Philosophy](design-philosophy.md).
- Looking for how a subteam works? See [Subteams](subteams/mechanical.md).
- Need the build season schedule? See [Season Timeline](build-season/timeline.md).
